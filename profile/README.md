### What we're building

SMMly is developing a practical platform for operating social media marketing services from one place.

- **Service management** — organize and manage a service catalogue.
- **Order operations** — create, manage and track customer orders.
- **Wallet workflows** — maintain customer balances and transaction records.
- **Reseller workflows** — support businesses operating their own customer-facing service.
- **Administration** — manage platform operations through a dedicated admin experience.
- **Developer integrations** — publish API documentation and integration tools as they become ready.

### Platform

The current SMMly application is a PHP-based panel designed for conventional PHP hosting environments, including cPanel, with a MySQL-compatible database.

SMMly's application code and infrastructure are maintained separately from this public organization-profile repository. Public developer resources will be published here when they are ready.
