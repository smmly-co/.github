### What SMMly does

SMMly brings the core operations of a social media marketing business into one platform.

- **Services** — structured service catalogue and service-level configuration.
- **Orders** — customer order creation, processing, tracking and lifecycle management.
- **Wallet** — balances, deposits, transaction history and controlled balance operations.
- **Resellers** — reseller-oriented workflows for businesses serving their own customers.
- **Affiliates** — affiliate codes, referral links and commission-related workflows.
- **Administration** — operational controls for platform management, users, services, orders and financial workflows.
- **Integrations** — API and payment infrastructure designed to connect SMMly with external workflows.

### Platform

SMMly's application is built with PHP and MySQL for deployment on conventional PHP hosting environments, including cPanel.

The product is designed as a complete SMM platform. Its public GitHub organization is used for organization information, community policies and developer-facing resources—not as a mirror of the private application source.
